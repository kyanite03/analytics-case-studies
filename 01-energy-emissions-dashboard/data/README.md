# Data: energy & emissions dashboard

The dashboard's generation and emissions figures are entered directly in `app/app.R` (summarised from the sources below), so the app needs no external data files. State boundaries come from the `ozmaps` package.

| Data | Source | Licence | In repo? |
|---|---|---|---|
| Electricity generation by source, 1990–2023 | DCCEEW, *Australian Energy Statistics 2024*, Table O. [Link](https://www.energy.gov.au/publications/australian-energy-statistics-table-o-electricity-generation-fuel-type-2022-23-and-2023) | CC BY 4.0 | No (download from source) |
| 2025–2050 generation path, 500 TWh 2050 demand | AEMO, *2024 Integrated System Plan*. [Link](https://aemo.com.au/energy-systems/major-publications/integrated-system-plan-isp/2024-integrated-system-plan-isp) | See AEMO copyright & permissions | No |
| Non-electricity emissions projections | DCCEEW, *Australia's Emissions Projections 2024* chart data. [Link](https://www.dcceew.gov.au/climate-change/publications/australias-emissions-projections-2024) | CC BY 4.0 | No |
