# Data: equity return clustering

- **Data:** daily returns for the 30 Dow Jones Industrial Average constituents (2,527 trading days, pre-2005 index membership), supplied as course data for a university machine-learning subject.
- **In repo:** no. The original source and licence of the extract are unknown, so it isn't redistributed. A comparable dataset can be built from public daily prices (e.g. CRSP or Yahoo Finance) for the same tickers, using `R_t = P_t / P_{t-1} - 1`.
- The analysis uses days 1201–2400 of the file. All results are in the rendered report.
