# Data: likelihood & GLM casework

Both datasets are public teaching datasets loaded directly in R, so no files are needed.
- **Titanic:** `datasets::Titanic` (ships with R), from British Board of Trade records (Dawson, 1995).
- **Palmer penguins:** `palmerpenguins::penguins` (Horst, Hill & Gorman, 2020), CC0. <https://allisonhorst.github.io/palmerpenguins/>
